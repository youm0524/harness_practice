# PRD: ApplyMate

## 목표
채용 지원서마다 반복 입력해야 하는 인적사항, 학력, 자격사항, 프로젝트 정보를 브라우저에 저장해두고 사용자가 요청할 때 현재 지원 페이지의 입력 폼을 자동으로 채운다.

## 사용자
- 여러 회사에 반복 지원하는 취업 준비생, 이직 준비자, 인턴 지원자
- 채용 플랫폼과 회사별 자체 지원 페이지를 오가며 동일한 정보를 반복 입력하는 사용자
- 개인정보를 외부 서버에 맡기지 않고 로컬 브라우저에 보관하고 싶은 사용자

## 핵심 기능
1. 사용자 프로필 관리
   - 인적사항: 이름, 생년월일, 이메일, 전화번호, 주소
   - 학력: 학교명, 전공, 학위, 입학일, 졸업일, 학점
   - 자격사항: 자격증명, 취득일, 발급처
   - 프로젝트: 프로젝트 제목, 기간, 역할, 주요 내용, 기술 스택
2. 현재 페이지 자동 채우기
   - Content Script가 `input`, `textarea`, `select`를 스캔한다.
   - `label`, `placeholder`, `name`, `id`, `aria-label`, 주변 텍스트를 기반으로 저장된 프로필 필드와 매칭한다.
   - 사용자가 popup에서 실행했을 때만 값을 입력한다.
3. 자동 채우기 결과 피드백
   - popup에서 채워진 필드 수와 실패/미매칭 필드 수를 보여준다.
   - 실패해도 페이지를 깨뜨리지 않고 사용자가 직접 수정할 수 있게 둔다.
4. 로컬 저장
   - 프로필 데이터는 `chrome.storage.local`에 저장한다.
   - MVP에서는 외부 서버, 계정 동기화, 원격 분석을 사용하지 않는다.

## MVP 제외 사항
- AI/LLM 기반 필드 추론
- 외부 서버 저장, 로그인, 클라우드 동기화
- 이력서 PDF 파싱 또는 자동 업로드
- 지원 사이트별 전용 어댑터 대량 구현
- 비밀번호, 주민등록번호 전체 번호, 금융 정보 등 고위험 민감정보 저장

## 디자인
- 매일 쓰는 브라우저 도구처럼 조용하고 실용적인 UI
- 팝업은 빠른 실행과 결과 확인에 집중한다.
- 옵션 페이지는 폼 편집이 오래 걸려도 피로하지 않도록 섹션형 레이아웃을 사용한다.
- 밝은 배경, 높은 가독성, 단정한 중립색, 신뢰감을 주는 녹색 포인트를 사용한다.
